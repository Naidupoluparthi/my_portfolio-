URL Phishing Attack Detection System

I built a real-time phishing URL detection system using Python, Flask, and machine learning algorithms (Random Forest and SVM) to classify malicious versus legitimate websites. The project included a user-friendly Flask web interface where users can input URLs and instantly receive threat analysis results. Key features such as URL length, domain age, and redirect count were engineered as inputs for the ML models, while all detection outcomes were logged into a MySQL database for tracking and analysis.
